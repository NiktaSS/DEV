# Проект Mesto

**Описание**  
Проект Mesto — это веб-приложение, позволяющее пользователям добавлять, редактировать и удалять карточки с изображениями. Каждая карточка содержит название и картинку, а также предоставляет возможность "лайкать" карточки и просматривать изображения в модальном окне.

**Функционал**  

- **Создание карточек**:  
  Карточки создаются на основе шаблона, используя функцию `createCard()`, и могут добавляться через форму.

- **Редактирование профиля пользователя**:  
  Модальное окно открывается по нажатию кнопки «Редактировать» с заполнением текущими значениями. Изменения сохраняются по нажатию кнопки «Сохранить».

- **Лайки и удаление карточек**:  
  Каждая карточка имеет кнопку "лайка" и иконку корзины для удаления.

- **Просмотр изображений**:  
  При клике на изображение карточки открывается модальное окно с увеличенной версией фотографии.

- **Плавные анимации**:  
  Все модальные окна открываются и закрываются с плавной анимацией.
